# Sapiq r41 · GitHub Pages — САЙТ + МОБИЛЬНАЯ PWA

Это **публичная интерактивная демоверсия** для партнёров. Ни сайт, ни PWA не подключают реальные счета, ордера, котировки или торговые уведомления.

## Что положить в GitHub

Загрузите **содержимое этой папки** (не ZIP как единственный файл) в корень отдельного публичного репозитория GitHub `sapiq-demo`:

```
.nojekyll
index.html               ← основной сайт и интерактивное демо
README.md
pwa/
  index.html             ← устанавливаемая PWA
  manifest.webmanifest
  service-worker.js
  icons/icon-180.png
  icons/icon-192.png
  icons/icon-512.png
```

**Не загружайте в публичный репозиторий backend-архивы, реальные ключи, пароли, токены, приватные ключи кошелька или данные пользователей.**

## Публикация

1. Создайте репозиторий на https://github.com/new, например с именем `sapiq-demo`, тип **Public**. Если репозиторий уже есть, используйте его, только если он предназначен для демо Sapiq.
2. Распакуйте архив. Откройте репозиторий → **Add file → Upload files** → загрузите `index.html`, `README.md`, `.nojekyll` и **папку `pwa` со всем содержимым**. В веб-интерфейсе GitHub папки можно загрузить через перетаскивание; проверьте, что после коммита пути `pwa/manifest.webmanifest` и `pwa/service-worker.js` действительно существуют. Если скрытый `.nojekyll` не загрузился, он не обязателен для этой сборки.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.
5. Дождитесь публикации и **откройте адрес из Settings → Pages**. Не отправляйте ссылки партнёрам, пока они не открываются.

**ОТДЕЛЬНЫЙ ЛИМИТНЫЙ ТЕРМИНАЛ В PWA:**

Эти адреса станут рабочими **только после включения GitHub Pages**. Если имя пользователя или репозитория другое, замените соответствующие части URL. Путь с `#/...` — это внутренняя маршрутизация одного HTML; перед ним обязательно должен стоять путь `sapiq-demo/` или `sapiq-demo/pwa/`.

## Проверка на смартфоне

- Откройте PWA-ссылку по HTTPS; в iPhone Safari используйте **Поделиться → На экран «Домой» → Добавить**, затем запустите приложение с новой иконки.
- На Android откройте ссылку в Chrome → **Установить приложение** (название пункта может отличаться).
- В терминале настройте тихие звуки нажатий; воспроизведение на мобильных требует прямого взаимодействия пользователя.
- Тестовые всплывающие сообщения внутри PWA не равны серверным Web Push. **На GitHub Pages закрытый iPhone не получит уведомления о вилках, пока не будет развернут отдельный HTTPS backend с push-подписками и подключённым потоком сигналов Sapiq.**
- Все цифры, спреды, заявки и ордера в демо — симуляция, а не реальные операции.

## Мини-чеклист после публикации

1. Основная страница, RU → EN → ES → 简体中文; одинаковые секции и кнопки.
2. Терминал: Live/Prematch, карточки, выбор вилки, калькулятор, режим трёх колонок, фильтры.
3. Лимитки: рынки → стакан → ордер → список ордеров; предупреждение об исполнении второй ноги.
4. Accounting: график и переключатели; расширение; звуки настроек.
5. PWA: в DevTools → Application проверьте manifest и service worker; после установки запустите приложение из иконки. В офлайне ранее открытая оболочка должна оставаться доступной.
6. На iPhone и Android проверьте фактическую прокрутку, размеры кнопок и возвращение из фонового режима.

**Важно:** GitHub Pages — хостинг для статического демо, не для приватных API и подписчиков. Публичный репозиторий могут просматривать третьи лица.
